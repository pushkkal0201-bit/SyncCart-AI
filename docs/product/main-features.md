# Product Features

## Punchline

> **See the shelf. Trust the cart. Keep checkout moving.**

Supporting technical line:

> **Camera observes what was taken. Phone records what was scanned. AI reconciles both.**

## Main feature: Shelf-to-Scan Reconciliation

```text
Physical Cart (Vision)  <->  Digital Cart (Customer Scan)
```

The system reacts when those realities remain inconsistent.

## Feature pillars

### 1. Vision-derived Physical Cart

- fixed CCTV / NVR RTSP support;
- Phone 1 hackathon camera profile;
- fixed-zone reference detector;
- optional YOLO detector;
- planogram-aware observations;
- temporal count stabilization;
- safe pickup/return event emission.

### 2. Customer Scan-and-Go

- anonymous session;
- barcode scanning;
- digital cart;
- duplicate-scan handling;
- private discrepancy prompts;
- checkout reconciliation.

### 3. Graduated Discrepancy Handling

```text
MATCH → VERIFY → NUDGE → REVIEW → RESOLVED
```

A temporary mismatch is not treated as wrongdoing.

### 4. Retailer Operations

- live session status;
- physical vs digital quantities;
- evidence and reason codes;
- exception-only review queue;
- targeted resolution.

### 5. AI Operations

- camera health;
- detector status;
- inference telemetry;
- frozen-stream detection;
- event arm/disarm;
- preview and reconciliation inspection.

### 6. Privacy by Design

- no facial recognition;
- no demographic profiling;
- no criminal-intent classification;
- anonymous temporary sessions;
- edge-first video processing;
- event metadata as the core business record.
